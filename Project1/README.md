A Menu-Driven Calculator, written entirely in C++ from scratch.

This program helps you perform basic arithmetic operations, like addition, subtraction, etc.

## Steps to run this program :
1. g++ Calculator.cpp -o Calculator (Compilation)
2. ./Calculator.exe (in Windows), and ./Calculator.out (in Mac/Linux)

## Concepts used :
1. Switch case
2. Standard I/O (scanf) and (printf) statements
3. Loop statements (while loop is used in this program)
